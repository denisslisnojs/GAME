# Публикация в Google Play — памятка

Тексты страницы — в [listing.md](listing.md), промпты для красивой графики — в [ai-prompts.md](ai-prompts.md).

## Что куда загружать (Play Console → «Основная страница магазина»)

| Поле | Файл |
|---|---|
| Значок приложения | `icon-512.png` |
| Обложка (Feature graphic) | `feature-graphic-en.jpg`, для переводов — `feature-graphic-{ru,pt,tr}.jpg` |
| Скриншоты телефона | `screenshots/captioned/<язык>/01…08` (первые три видны без прокрутки — они самые сильные; `09-tree` — запасной) |
| Скриншоты планшета 7" и 10" | те же файлы подходят (1920 × 1080, 16:9) |
| Название, краткое и полное описание | `listing.md` |

## Анкеты раздела «Контент приложения»

- **Категория:** Игры → Стратегии. Теги: «Средневековье», «Стратегия», «Одиночная игра», «Офлайн».
- **Целевая аудитория:** 13+ (не отмечай детские возрасты — иначе действуют строгие правила Families).
- **Реклама:** «Нет рекламы» (пока в игре её нет; поменяешь, когда добавим).
- **Безопасность данных:** игра не собирает и не передаёт данные — сохранения хранятся только на устройстве,
  сетевых запросов нет. Ответ: «Данные не собираются».
- **Возрастной рейтинг (IARC)** — отвечай честно:
  - насилие: да, мультяшные сражения холодным оружием, кровь есть, но её можно выключить в настройках;
  - азартные игры: **имитация** — в таверне есть кости и ставки на турнирах на игровую валюту, реальных денег нет;
  - покупки, чат, передача местоположения: нет.
- **Политика конфиденциальности:** Play Console попросит ссылку. Могу написать текст и опубликовать страницу.

## Что ещё нужно до выпуска

1. **Сборка для релиза.** Сейчас CI собирает отладочный APK с общим debug-ключом. Для Play нужен **AAB, подписанный
   личным ключом загрузки** (upload key), и включённая подпись приложений Google Play. Могу настроить сборку AAB
   в CI — ключ создаёшь сам и кладёшь в секреты GitHub, в репозиторий он не попадает.
2. **Закрытое тестирование.** Для новых личных аккаунтов разработчика Google требует перед выходом в продакшн
   закрытый тест: не меньше 12 тестировщиков в течение 14 дней подряд.
3. **Контакты разработчика:** e-mail (обязательно), сайт — по желанию.

## Как пересобрать картинки

Нужен запущенный dev-сервер: `npx vite --port 5173`.

```bash
node dev/store-shots.cjs en        # скриншоты без подписей (ru | en | pt | tr)
node dev/store-shots.cjs en feature  # кадр боя для обложки → store/feature-bg.jpg
node dev/store-captions.cjs        # скриншоты с подписями для всех языков
node dev/store-brand.cjs           # иконка, заставка, герб (рисует dev/brand.html)
node dev/store-feature.cjs         # обложки 1024 × 500
```
