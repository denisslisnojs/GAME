# Warfare 1347

Средневековая песочница в духе Mount & Blade: уменьшенная карта Евразии 1347 года, четыре державы,
найм и прокачка войск, торговля, сражения с видом сбоку и захват городов.

Дизайн игры описан в [docs/GDD.md](docs/GDD.md).

## Что уже есть

### Этап 1: карта и поселения

- Главное меню, создание героя, выбор державы: Аурелийская империя, Нордмарк, Орда Синего Неба, Султанат Аль-Захра.
- Пиксельная карта Евразии по реальным очертаниям (Natural Earth): биомы, горы, реки, озёра, территории держав.
- 34 города, 18 замков и 83 деревни. У каждой культуры свой облик поселений.
- Перемещение отряда касанием с поиском пути (A*): скорость зависит от местности, моря пересекаются на корабле.
- Время в реальном масштабе с паузой (пробел) и скоростями ×1, ×2, ×4, смена дня и ночи.
- Найм крестьян в деревнях и конницы в городах и замках, запас рекрутов восполняется каждый день.
- Рынок с фиксированными ценами, окно отряда с характеристиками воинов, обзор держав.
- Автосохранение, процедурная средневековая музыка (лютня, флейта, бурдон), настройки громкости.
- Карта кэшируется в IndexedDB: повторный запуск не генерирует её заново.

### Этап 2: бои
- Отряды на карте: разбойники, степные и пустынные налётчики, морские разбойники, дезертиры,
  разъезды враждебных держав. Бродят, преследуют слабых, убегают от сильных, со временем крепнут.
- Встреча: составы армий, соотношение сил, выбор построения, бой, автобой или отступление.
- Бой с видом сбоку: бойцы свободно ходят по полю вперёд-назад и вглубь, обходят своих, распределяются по целям;
  до 36 бойцов на сторону и подкрепления волнами, параллакс-фон по местности.
- Механики: типы урона и брони, криты, уклонения, блоки щитом, таранный удар конницы,
  бонус копий против конницы, ограниченный колчан, боевой дух и бегство.
- Команды группам (герой, пехота, стрелки, конница): «В атаку», «Стоять», «Отступить».
- Поддержка: залп, колья против конницы, боевой клич, дымовая завеса.
- Итоги: погибшие и раненые, опыт отрядам и герою, уровни героя, трофеи: золото и товары.
- Повышение воинов в окне отряда: за опыт и золото, с выбором ветки на развилке; значок на кнопке «Отряд».
- Боевая музыка (барабаны, бас, медь) и синтезированные звуки боя.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
```

## APK для Android

Каждый push запускает GitHub Actions (`.github/workflows/android.yml`), и тот собирает отладочный APK.
Скачать его можно на странице запуска workflow, в блоке **Artifacts** → `warfare-1347-apk`.

Сборка локально (нужны Android SDK и JDK 21):

```bash
npm run android:init   # один раз: создать android/ и настроить ориентацию, иконки
npm run android:sync   # собрать веб-версию и скопировать её в android/
cd android && ./gradlew assembleDebug
```

## Структура

| Папка | Что внутри |
|---|---|
| `src/data` | державы, поселения, войска, товары, данные суши |
| `src/map` | генерация пиксельной карты, поиск пути, территории |
| `src/game` | состояние игры, мир, игровая логика |
| `src/gfx` | процедурный пиксель-арт: поселения, отряды, портреты, гербы |
| `src/scenes` | сцены Phaser: загрузка, глобальная карта, бой |
| `src/battle` | симуляция боя, армии, облик воинов, фон поля |
| `src/ui` | DOM-интерфейс: меню, HUD, окна |
| `src/audio` | процедурная музыка |
| `scripts/build-land.mjs` | подготовка контуров суши из Natural Earth |
| `dev/` | страницы для разработки: галерея спрайтов, тестовый бой, баланс (`npx tsx dev/simtest.ts`) |
